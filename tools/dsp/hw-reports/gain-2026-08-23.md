Model: wire word is Q1.31; scatter shifts `>>3` to Q4.28; gain is
`fr.gain(x, to_q(g))` = `sat32(rns(x·g, 28))`; gather shifts `<<3` back.
End to end the hardware reproduces the reference exactly.

**One thing this does NOT settle.** `to_q()` rounds to nearest while the
SHARC `fix` instruction truncates toward zero, so the two models can differ
by 1 LSB in the gain coefficient. At all thirteen gains chosen here the two
predictions are *identical*, so this run does not discriminate between
them. A coefficient landing exactly on a .5 boundary would; that is worth
adding to the vector set rather than assuming the question is closed.

Build: `DSP4_STRIPS=1`, chips `8326e9d4…` / `24b92fd2…`, CPLD
`dsp4_logic_loopback.2b00c3e17e2a` (captures `B_O3` slot 0 =
`C2_MAIN_ST_OUT`). Requires the ramp-engine fix — before it, every level
produced identical output.
